# Workbench surface contract

Mode: Operate

THESIS: 沿用已批准的 myEnv Windows 工作台。用户能区分本机 PATH 中已有的安装、独立的 myEnv 默认工具链、项目生效环境、目标草稿和执行中的任务，在普通与最小窗口中完成检查、选择、保存、预览、确认和运行。

OWN-WORLD: 森林绿与暖中性色，浅色白工作面、深色灰绿工作面，Segoe UI 与中文系统字体回退。紧凑原生控件、细分隔线、Devicon 原彩语言标志与 Lucide 操作 SVG。实际 token 与复用规则以 ../../DESIGN.md 及 ../design.json 为准。

STORY: 首次可跳过，或检查本机并可另选一个项目目录 → 检查完成后保存记录。日常分别查看本机安装、Node/Python 包记录与管理与 myEnv 工具链；项目或默认工具链仍遵循选择语言 → 查询或手输版本 → 明确保存声明 → 预览整个目标环境 → 确认同步 → 运行。查询、失败、取消、构建许可与结果来自真实任务接口。运行结果交给独立终端；GUI 只表达终端交接状态。

FIRST VIEWPORT: 保留真实 Windows 标题栏、叶片应用图标和系统按钮，标题栏颜色与紧邻的项目工具栏协调。普通窗口使用语言侧栏，选中语言下放置轻量工具快捷入口；窄窗转为语言横条，工具入口移至当前页签下一行。保存/预览确认等页内操作栏与任务底栏固定，首次检查弹窗的标题、跳过入口和主按钮固定。每个阅读区域只有一个细淡滚动条，来源证据和原始日志由所在正文统一滚动。按需抽屉覆盖工作区，包含概览、日志、只读历史；主工作区 inert，许可决策栏固定。

FORM: Wails v2 原生 Windows 窗口内的 React/TypeScript 生产客户端，共用 Go 内核。system/light/dark 只通过偏好设置控制，客户端与原生外观同步。前端图标为本地 SVG；Windows 图标由 `build/windows/icon.svg` 生成多尺寸 ICO 并嵌入 GUI 原生资源，无额外设计工具运行依赖。

FINISH: rc.11 沿用用户批准的工作台。原生第一批9张布局与真实单包闭环位于 `.build/rc11/screen-runs/20260914-152346-089-69729c19`，独立设计审核 ship / faithful；确认批次5张及真实批量、404、查询取消位于 `.build/rc11/screen-runs/20260914-152810-037-8adbed09`。工具快捷入口最终原生确认位于 `.build/rc11/screen-runs/20260914-160424-679-f1404921`，其中普通/最小窗口浅深色4张经独立设计确认 ship / faithful。最小外窗760×540中的抽屉标题、关闭、预览/确认和底部任务区可达。功能与交付以 docs/implementation.md 为准，不从截图推导性能、IME或跨平台验收。

## Interaction invariants

- 原生默认/最小外窗 1100×780 / 760×540，本轮客户端 1084×741 / 744×501。优先保留当前信息、目标输入与主动作；尺寸随原生框架和缩放变化，不把截图像素当作跨 DPI 保证。
- 本机命令按应用启动时 PATH 解析，记录包含实际版本、位置和检查时间；终端配置或后续 PATH 变化可能不同。myEnv 默认工具链独立显示，检查不接管安装、不改 PATH。首次检查可跳过，保存的是检查快照，之后可在维护中重新打开。
- Node/Python 包按项目、全局安装位置或解释器分组，管理工具另列；缺失、未核验与检查范围明确，行尾管理打开右侧抽屉；包组可搜索、选择和全选，默认10项，其余折叠；管理工具全部展示。单包/同位置批量管理遵循官方查询→期望→预览→确认→逐项结果，主操作与底栏固定。Java/Go/Rust 项目检查保留对应版本页，不渲染其他生态的包说明。
- 工具快捷入口只属于当前选中语言，不与语言并列为一级卡片；仅展示已检测的uv/pip/npm/pnpm。pip绑定具体解释器，项目pip不借用本机环境；uv保持独立工具身份。同名多位置先选择安装，进入抽屉后以所选路径为准；关闭后恢复可见入口焦点，包括打开期间发生窗口尺寸切换的情况。“更多…”仍进入完整包与工具页。
- 维护、设置和外部管理保留返回入口；检查失败/取消返回对应检查工作区。查询选项通过外部点击、Esc、导航或查询动作收起；Esc 恢复入口焦点。Java 8 同时标注 1.8，稳定版本优先，预发布显式开启。
- 查询有真实进行中、失败恢复与取消收尾。仅真实 download 事件显示当前文件进度；未知 total 保持不定进度。阶段是去重概览，不承诺严格执行顺序。
- 流式更新不抢输入焦点。打开抽屉聚焦页签；Esc 可收起；日志按当前任务保存滚动位置，只有在尾部时自动跟随。
- 历史只读，不携带其他任务的执行按钮；构建许可仅绑定当前待确认任务。产品的保存、锁、失败保留旧代等约定继续由 docs/architecture.md 定义。

本文件是开发契约，位于 frontend/dist 之外，不随客户端静态资源发布。原型继续保留在 .build/impeccable-mvp，并保有“模拟数据”身份。
